## 生成の際の注意
本文の日本語フォントには「源ノ明朝」が指定されていて、そのままではローカルにインストールされているフォントファイルが参照されます。
このローカルのフォントファイルが OpenType 形式であったりバリアブル TrueType 形式であったりすると、PDF 生成の際に該当フォントが Type 3 形式で埋め込まれる可能性が高いです。
印刷所によっては Type 3 形式に対応していないことが多いので、このままでは入稿できない PDF が生成されることになります。

`out` ディレクトリ内に以下のフォントファイルを保存しておくと、そのファイルが参照されるようになっています。
ここに (バリアブルでなく埋め込みに対応した) TrueType 形式のフォントを置いておくことで、PDF 生成の際に該当フォントを埋め込みサブセット形式にすることができます。
- `japanese-serif-400.ttf` — 「源ノ明朝」or「Noto Serif JP」の Regular
- `japanese-serif-500.ttf` — 「源ノ明朝」or「Noto Serif JP」の Medium
- `japanese-serif-700.ttf` — 「源ノ明朝」or「Noto Serif JP」の Bold
